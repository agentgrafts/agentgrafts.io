# Build once. Graft anywhere.

AgentGrafts is an open format for packaging the knowledge behind a verified feature so an AI agent can rebuild it in a new project.

It sits beside the two building blocks you already know:

<Columns cols={3}>
  <Card title="MCP" icon="plug" href="https://modelcontextprotocol.io/">Connect an agent to data, tools, and workflows.</Card>
  <Card title="Agent Skills" icon="sparkles" href="https://agentskills.io/home">Teach an agent how to perform a class of tasks.</Card>
  <Card title="AgentGrafts" icon="code-branch" href="/why-grafts">Carry a concrete feature's intent, constraints, and proof into a new codebase.</Card>
</Columns>

<Info>
  Grafts are knowledge assets, not source-code dumps. They preserve what must remain true while leaving implementation details to the host project.
</Info>

## The shortest path from idea to implementation

<Steps>
  <Step title="Extract">Describe a verified feature from its source project: intent, behavior, constraints, interfaces, dependencies, and acceptance criteria.</Step>
  <Step title="Package">Put that knowledge in a versioned directory with a `GRAFT.md` file. Add references, adapters, tests, or assets only when they help an agent adapt the feature.</Step>
  <Step title="Apply">Give the Graft to an agent in a new project. The agent maps the contract to the local stack, implements the feature, and checks the acceptance criteria.</Step>
</Steps>

<Card title="Create your first Graft" icon="rocket" href="/quickstart">Start with a feature that already works. Turn its behavior into a portable contract in a few minutes.</Card>

## A format designed for progressive disclosure

At discovery time, an agent needs only `name` and `description`.
When a task matches, it loads the full `GRAFT.md`.
Only then does it pull in optional references or execute bundled tests.

```text
my-feature/
├── GRAFT.md
├── references/
├── adapters/
├── tests/
└── assets/
```
